# Security
Report vulnerabilities privately using GitHub private vulnerability reporting when enabled; do not attach private screenshots to public issues. Supported development branch: main, 0.1.x alpha.

No accounts, telemetry, uploads, listeners or screenshot network requests. Quiet public GitHub release checks run at startup and every six hours; downloads require a user action. Update requests never include screenshots or OCR text. Images and OCR text are sensitive. Use synthetic assets in reports. The application does not log image contents, window titles or OCR text. See [threat model](docs/THREAT-MODEL.md).

Build-time NuGet/model downloads and runtime GitHub release checks/downloads require network. Updates admit only this repository’s HTTPS release URLs, require GitHub’s SHA-256 asset digest, and use the installed validator to check bundled checksums before executing downloaded installer scripts. This verifies integrity, not publisher identity; a compromised release publisher can supply malicious code. Release signing keys belong in a protected external signing service or repository secrets, never source control. GitHub secret scanning and push protection are enabled; recheck hosted settings for each release.
