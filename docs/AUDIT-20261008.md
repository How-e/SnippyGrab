## Findings and changes

1. **Transfer deadline regression:** starting another transfer or releasing its lease assigned `now + 24 hours` even when that was earlier than the persisted deadline. A backward clock correction could let cleanup delete a receiver's source before the previously promised deadline. [PR #15](https://github.com/How-e/SnippyGrab/pull/15) keeps the later deadline. Both restart/cleanup regression cases failed against main and pass with the fix. Existing persistence failure, immutable revision and crash/expiry tests remain green. This preserves promised wall-clock deadlines; it does not guarantee elapsed time across arbitrary clock changes.
2. **Single-image drag overhead:** the UI thread decoded and then encoded a complete PNG for a revision already stored as a lossless PNG. The optimized path retains bitmap/file-drop representations and reads the stored PNG bytes directly. A regression fixture with PNG text metadata failed against main and passes after the change, including payload stability after a subsequent edit. Multi-image file ordering and durable transfer leases retain their existing paths.
3. **Stale architecture inventory:** ARCHITECTURE.md still described the replaced native engine as Tesseract 5.0.0 / Leptonica 1.82.0. It now describes the verified source-built replacement; older DLL filenames are ABI compatibility names.

No additional actionable defect was established in the reviewed capture, geometry/DPI, hotkey, dock/selection, editor/undo/effects, pin/history, settings/startup, cache/recovery/export, OCR/clipboard, installer or release boundaries. This is a bounded source and runtime audit, not proof that all defects have been eliminated.
