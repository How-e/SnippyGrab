# Capture timing records

Every admitted capture logs `capture_started` and one `capture_finished` record with the same operation ID. The final JSON identifies mode, outcome and exception type when applicable, excluding exception messages and screenshot/OCR/path content. A missing final record identifies an interrupted operation; cancellation and storage/clipboard fallback are explicit outcomes.

`InteractiveTotalMs` includes monitor picking and human region/window selection time. It is not an application-processing latency. `RequestToOverlayMs` ends when the overlay is shown. For region captures, `SelectionToClipboardMs` starts in the successful mouse-up handler before overlay teardown and ends only after successful clipboard publication. Window picking starts this interval at the accepting click. Automatic desktop/active-window/monitor captures have no selection interval. Failed or disabled clipboard delivery has no success latency. `SelectionToStoredMs` ends after pixels and attempted history persistence return; `HistorySaved` distinguishes pending history warnings.

`PhaseMilliseconds` splits hide preparation, acquisition, crop, encoding queue, encoding, storage and clipboard work. Acquisition/crop include their worker queue waits. The encoding queue ends when the delivery delegate starts, so a slow export, storage write or busy clipboard can be distinguished from actual PNG encoding. Phase durations are not a complete partition of the request; overlay teardown, dock refresh and UI scheduling can add time. A phase that did not run is absent. `ClipboardOnly` means storage failed but copying preserved the image; `PreservationFailed` means neither path succeeded. Mode and status are written as names.

The old `capture_total_ms` and combined `capture_ready_ms` entries are replaced by this explicit record. Existing historical logs retain their old meaning. Timing is local and uses a monotonic clock. Synthetic timing tests do not certify physical end-to-end responsiveness across every display or clipboard receiver.
