## Current implementation

- Capture supports region, desktop, window, active window and an explicitly selected monitor. Monitor identity/topology guards and a disabled-by-default picker shortcut preserve existing settings.
- Local English OCR validates its pinned model/native components and provides readiness guidance. Additional languages and runtime model downloads remain excluded.
- Single and ordered batch exports share PNG/JPEG/WebP options, path guards, revision leases and cancellation. PNG preserves cached bytes; WebP has a 16 MP / 16383-axis cap. Late Skip collisions remain skipped instead of overwriting a new file; metadata failures remain distinguishable from exported files.
- Composition combines 2–20 captures into native-pixel strips/grids. Source thumbnails, layout/order guidance, bounded previews and visible creation controls support review before creating a new PNG.
- Assisted scrolling captures a fixed viewport in static vertical content. It explains selection, scrolling and seam review; supports trim/correction/reject/undo, confidence rejection and every permitted integer overlap; and enforces frame/time/staging/image limits. It never scrolls automatically or admits individual staged frames into history.
- The dock uses translucent controls over the image, with visible selection/focus/high-contrast cues. Delete stays on the main toolbar at every supported thumbnail size and hides the selected captures or the clicked capture. Tray text, shortcuts and icons share a row center; dialog titles align with their icons.
- Quiet GitHub release checks run at startup and every six hours. Updates require an explicit user action, repository HTTPS URLs, a GitHub asset SHA-256 digest and bundle checksums. The installed validator checks the downloaded bundle before its installer scripts run. Installed/portable updates preserve captures/settings and previous application files. Source builds are alpha and cannot update in place; legacy dated alpha tags compare by date/revision.
- Signing hooks require a protected identity and timestamp. Real publisher signing remains an external prerequisite. Recording/GIF functionality remains excluded under [ADR-002](ADR-002-RECORDING-SCOPE.md).
